Mi Mapa ZMG BETA

Plataforma web de planificación de rutas multimodales. Optimización de traslados urbanos integrando transporte masivo y tradicional mediante algoritmos de grafos y análisis geoespacial.

* Proyecto en constante desarrollo y aprendizaje.

La Inspiración

La idea de crear esta aplicación nace del deseo de utilizar y recuperar la estética de los mapas topológicos clásicos de las redes de transporte. Buscamos transformar la complejidad de la movilidad urbana de la ZMG en una experiencia visualmente limpia, intuitiva y altamente funcional.

El Motor Detrás del Mapa

🗺️ Topología Vectorial

Renderizado dinámico de la red de transporte utilizando geometrías LineString. Normalización de toponimia urbana y cartografía oficial de rutas.

🧮 Algoritmo Dijkstra

Motor de ruteo personalizado operando sobre un grafo de adyacencia dirigido. Ponderación de distancias, transbordos y direccionalidad estricta para evitar rodeos en vialidades de un solo sentido.

📍 Conexión Multimodal

Cálculos de proximidad perimetral y medición geodésica (fórmula de Haversine) para trazar rutas peatonales desde la ubicación GPS en tiempo real del usuario hasta la estación más cercana.

🌐 Integración de APIs Externas

Consumo e integración de servicios REST de terceros para geocodificación de lugares (Nominatim), capas de tráfico en tiempo real y enrutamiento vehicular/peatonal (Mapbox), y pronóstico meteorológico geolocalizado (Open-Meteo).

Stack Tecnológico

Arquitectura cliente-servidor con separación estricta de responsabilidades y exposición vía API REST CORS.

Java Spring Boot Spring Security PostgreSQL + PostGIS Hibernate Spatial Leaflet.js Mapbox API QGIS (Canal ETL)

Desarrollado para la Zona Metropolitana de Guadalajara (ZMG).
